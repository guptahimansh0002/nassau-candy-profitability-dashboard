## 📌 Project Overview

Nassau Candy lacks visibility into which product lines drive real profit versus products that only create sales volume. I built an end-to-end profitability analysis across **3 divisions**, **15 products**, and **5 factories**. The final deliverable includes an interactive **Streamlit dashboard** and a **PDF executive report** for leadership review.

## 🏢 Company Background

Nassau Candy was founded in **1920** in **Hicksville, NY**. The company is a manufacturer, importer, and distributor of specialty confections and gourmet foods. Nassau Candy manages **10,000+ SKUs** across **3 divisions**: Chocolate, Sugar, and Other. This project also maps products to **5 factories**: Lot's O' Nuts, Wicked Choccy's, Sugar Shack, Secret Factory, and The Other Factory.

## 📊 Derived KPI Columns

| KPI | Formula | Description |
|---|---|---|
| Gross_Margin_Pct | `(Gross Profit / Sales) * 100` | Measures gross profit as a percentage of revenue |
| Profit_Per_Unit | `Gross Profit / Units` | Measures average gross profit per unit sold |
| Revenue_Contribution_Pct | `Product Sales / Total Sales * 100` | Shows each product's share of total revenue |
| Profit_Contribution_Pct | `Product Profit / Total Profit * 100` | Shows each product's share of total gross profit |
| Margin_Flag | `High >= 40% / Medium 20-39% / Low < 20%` | Classifies products by margin strength |
| Factory | `Mapped from Product Name` | Adds a supply chain view to product profitability |

## 🧮 KPI Formulas

| KPI | Formula | Description |
|---|---|---|
| Gross Margin % | `Gross Profit / Sales * 100` | Compares profitability across products regardless of sales volume |
| Profit Per Unit | `Gross Profit / Units` | Identifies products that generate strong profit per item sold |
| Revenue Contribution % | `Product Sales / Total Sales * 100` | Measures how much each product contributes to company revenue |
| Profit Contribution % | `Product Profit / Total Profit * 100` | Measures how much each product contributes to company gross profit |
| Cost-to-Revenue Ratio | `Cost / Sales` | Flags products where cost consumes too much revenue |

## ⚙️ Installation & Run

### Option A — Run Locally

```bash
git clone https://github.com/yourusername/nassau-candy-analysis.git
cd nassau-candy-analysis
python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python scripts/clean_nassau_data.py
python scripts/nassau_eda_charts.py
python scripts/profitability_analysis.py
python scripts/generate_nassau_report.py
streamlit run app.py
```

Access: <http://localhost:8501>

### Option B — Run with Docker (Recommended — no Python install needed)

```bash
# Install Docker Desktop: https://www.docker.com/products/docker-desktop
git clone https://github.com/yourusername/nassau-candy-analysis.git
cd nassau-candy-analysis
docker-compose up
```

Access: <http://localhost:8501>

### Docker Commands

```bash
docker-compose down
docker-compose up --build
docker run -p 8501:8501 nassau-candy-dashboard
```
